# Space Trace

**Space Trace** is a story-driven sci-fi exploration game prototype for the NASA Space Apps Challenge 2026 theme **“Abandoned but Not Forgotten.”**

Earth is missing. The Moon is not empty. In this first playable slice, an extraterrestrial investigator scans Tranquility Base and reconstructs the story of the equipment humanity left behind.

## Play the prototype

Open [`index.html`](./index.html) in a browser. No build step or package installation is required.

To publish with GitHub Pages:

1. Upload this folder to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main`, and select `/ (root)`.
4. Save and open the generated Pages URL.

## Included in this prototype

- A playable lunar investigation scene
- Three interactive evidence markers
- A recovered evidence field log
- A narrative timeline reconstruction
- NASA Apollo 11 source attribution
- Responsive layout for desktop and mobile

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | Game interface and content structure |
| `styles.css` | Visual design, lunar scene, responsive layout |
| `app.js` | Evidence collection and game state |

The story is fictional, while the mission details are based on NASA's Apollo 11 mission information. The prototype intentionally uses a CSS illustration so it can be uploaded and played without an asset pipeline.
